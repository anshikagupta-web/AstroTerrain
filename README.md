# AstroTerrain 🌍🚀

An AI-powered geospatial platform for identifying
Earth locations that serve as analogs for lunar
and Martian exploration sites.

## NASA Space Apps Challenge 2026

### Project Overview

AstroTerrain uses satellite imagery, geospatial
analysis, and machine learning to compare Earth's
terrain with planetary environments.

## Tech Stack

- Frontend: React.js
- Backend: Python, FastAPI
- Database: PostgreSQL + PostGIS
- Visualization: CesiumJS / Deck.gl
- Machine Learning: Python, Spatial ML
- Geospatial Processing: Rasterio, GeoPandas

## Project Modules

### Module 1: Frontend
UI/UX, navigation, state management, and filters.

### Module 2: Globe Visualization
3D terrain visualization and spatial mapping.

### Module 3: Backend & Data Pipeline
FastAPI, PostgreSQL, PostGIS, and satellite data processing.

### Module 4: ML Engine
Spatial similarity matching and AI-generated mission reports.
